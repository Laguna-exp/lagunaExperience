# Laguna Experience — Carrusel de experiencias

## Archivos

- index.html
- styles.css
- script.js

## Funcionamiento del nuevo botón

El cuadradito que aparece arriba a la izquierda de cada tarjeta ahora es un `<button>`.

Al presionarlo:

1. Se abre un modal.
2. Aparece un carrusel.
3. Se muestran 3 imágenes relacionadas con esa experiencia.
4. Se puede avanzar con `›`.
5. Se puede volver con `‹`.
6. Se puede elegir una imagen desde los puntos inferiores.
7. Se puede cerrar con `×`.
8. También funcionan las teclas ←, → y Escape.

Las imágenes se cargan desde URLs de imágenes de Unsplash para que no sea necesario descargar archivos de imágenes dentro del proyecto.

## Ejecutar

Abrí `index.html` en un navegador moderno.

Necesitás conexión a Internet para cargar las imágenes del carrusel y la tipografía.
